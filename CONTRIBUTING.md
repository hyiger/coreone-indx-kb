# Contributing

The contribution guide is published as part of the site and lives at
[`docs/contributing.md`](docs/contributing.md) so that it appears in the site
navigation. That file is the single source of truth — this pointer exists so that
GitHub's contribution prompts find something at the conventional location.

Read it there: **[docs/contributing.md](docs/contributing.md)**

The short version:

- Every page declares a `confidence` tier — `measured`, `reported` or
  `provisional` — in its front matter. This is the site's core convention.
- **Never publish a number without a tier**, and never publish a calibration value
  that a human has not verified on hardware.
- No verbatim forum or Discord content. Extract the finding, write it in your own
  words, link the source.
- Superseded pages are marked with `superseded_by`, never deleted.

See also [`CLAUDE.md`](CLAUDE.md) for the same rules in the form used by automated
tooling.
